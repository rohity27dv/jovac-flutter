# Smart Café - Simple Flutter Assignment

Minimal single-screen Flutter app matching the UI in the provided screenshot. Features:

- Category dropdown (Burger, Pizza, Sandwich, Cold Coffee, French Fries)
- Selected item card with image, description and options menu
- Quantity increment/decrement
- Place order / Save for later / Clear selection
- Today's special modal and floating action button

Run:

```bash
flutter pub get
flutter run
```

Files:

- `lib/main.dart` - main app

You can now commit these files and push to GitHub.
